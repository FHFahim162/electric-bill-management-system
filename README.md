# electric-bill-management-system
A Java desktop application for managing electricity billing, including user registration, authentication, bill generation, invoice viewing, payment management, and profile updates.
A Java-based desktop application for managing electricity billing and customer information. The system provides a simple graphical user interface for user registration, login, profile management, bill generation, invoice viewing, and bill payment.

## 📌 Project Overview

The **Electric Bill Management System** is developed using **Java** and provides a user-friendly interface for managing electricity billing-related tasks.

The application allows users to:

- Register and manage user accounts
- Log in securely using their credentials
- View and update profile information
- Generate electricity bills
- View detailed bill invoices
- Calculate VAT and late payment charges
- Make bill payments
- Save invoices to a selected location
- Manage applicant/customer information

## ✨ Features

### 🔐 User Authentication

- User registration
- Login system
- Password visibility toggle
- Remember-me option

### 👤 User Management

- View user details
- Update profile information
- Manage customer/applicant data

### 🧾 Bill & Invoice Management

- Generate electricity bills
- Calculate total bill amount
- Apply VAT
- Calculate late payment charges
- Preview invoices
- Save invoices as files

### 💳 Bill Payment

- View generated bill information
- Record payment information
- Maintain payment records
